# 📝 Todo App

A simple and responsive **Todo Application** built using **HTML, CSS, and Vanilla JavaScript**.  
This app helps users manage daily tasks by adding, completing, and deleting todos.

---

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean UI
- Fully responsive design
- No external libraries used

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the app  
- **CSS3** – Styling and layout  
- **JavaScript (ES6)** – App logic and DOM manipulation
